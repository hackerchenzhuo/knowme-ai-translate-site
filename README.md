## 两款工具

| 工具 | 用途 | 安装 |
|---|---|---|
| **论文雷达** | 多维评分、缓存复用，整理适合自己的论文清单 | [Chrome 商店 ↗](https://chromewebstore.google.com/detail/aneomkhamcijmfmeeegocbknklflilof) |
| **AI 翻译** | 划词或快捷唤起，保留 Markdown 结构与个人译法 | [Chrome 商店 ↗](https://chromewebstore.google.com/detail/ggbnigoglmfkdfmjggiifmfoinncblgm) |

免费安装。AI 翻译使用自己的模型连接，模型服务可能计费。

## 让排序，贴近你的研究

研究相关性、作者与机构证据、时效和个人偏好分层加权，形成你的选读顺序。研究方向与公开证据变化，私人权重随之调整。[了解评分与图谱 ↗](https://hackerchenzhuo.github.io/knowme-ai-translate-site/#ranking)
