知我AI翻译隐私说明

版本：2.4.1；更新日期：2026-10-01。开发者发布名：ZhuoCs。

知我AI翻译（KnowMe AI Translate）使用你提供的 所选 AI 厂商的 API Key 或你获准使用的兼容服务。没有开发者运营的翻译代理、账号系统、广告、统计或分析服务，不将数据发送给扩展开发者。

本扩展按 Chrome Web Store 用户数据政策的 Limited Use 用途限制处理信息：只用于这里说明的翻译、阅读、缓存和用户控制的偏好功能，不出售数据，不用于广告、征信或无关用途；开发者没有读取你的译文或个人记忆的后台。向你选择的服务传输，仅为完成你启用的相应功能。

翻译请求

扩展将你划选、粘贴、输入或主动打开的 TXT / Markdown 文字，以及翻译提示、语言、阅读场景和实际匹配的少量个人偏好，经 HTTPS 发给设置中的服务。默认划词先显示按钮；启用直接翻译时，划选即触发请求。所选内容中的代码、引用和表格可能随文字发送。每次最多 20,000 字符，个人偏好附加提示总计最多 512 UTF-8 字节。

API Key 仅用于向该服务认证。Google 原生模式使用 generativelanguage.googleapis.com；其他厂商或兼容网关使用设置中所示的 HTTPS 地址。服务提供方依据自身条款处理和保留数据，并可能收费；公司服务须取得相应授权。扩展不读取账号密码或浏览历史，不为翻译读取未选中的整页正文。

可选快速入门

首次安装打开快速入门页，更新不打断阅读。可以跳过，也可从设置重新打开。教程仅在你点击翻译时把公开示例文本发送到已配置服务，可能消耗模型额度；纠正需你显式保存。教程复用正常翻译、缓存和个人译法功能，不伪造结果，不新增分析追踪或上传教程进度。

主动连接测试

“保存并测试连接”仅在主动点击后向当前保存的服务发送一次固定 Hello 翻译请求与固定指令，使用当前模型和 Key；不发送你的自定义提示、历史、原文或个人术语。请求输出上限 1,024 token，本机回复上限 256 字符，20 秒超时，可停止且不自动重试。服务可能收费。界面暂时显示耗时及成败，不保存回复正文，不创建翻译、反馈或学习记录。普通保存不发起测试。

可选剪贴板读取

“粘贴并翻译”需你主动允许 clipboardRead 权限。翻译快捷键优先使用网页选区，无选区时仅在已获授权后读取一次剪贴板并发送到你配置的翻译服务；未授权则提示点击按钮授权。没有剪贴板轮询、后台收集或自动发送监听。可在 Chrome 扩展权限中撤销读取权限，仍可手动粘贴。

本机连接、缓存与记忆

连接配置、API Key、译文缓存、个人偏好、反馈和 Jev 配置使用 AES-GCM 256 位加密后保存在当前浏览器，不同步到浏览器账号。加密密钥由你设置的本机口令经 PBKDF2-SHA256（600,000 次）生成；口令不保存、不联网。浏览器会话存储暂存解锁密钥与工作数据，限制为受信任扩展上下文；浏览器重启或扩展更新后需再次解锁。界面主题、尺寸和划词开关等普通偏好不加密。忘记口令无法恢复加密记忆。

旧版数据在你设置口令后迁移：先写入并验证密文，再删除原活动存储项；失败保留原数据。此过程不承诺清除磁盘历史残留。已经解锁的扩展仍须使用明文处理请求；加密不能防御已控制浏览器或操作系统的软件。旧版口令加密数据需原口令恢复。

译文缓存新安装默认开启、保留 30 天，可设置 1–365 天，最多 500 条 / 约 6 MiB；已有用户沿用已有设置。包含成功的原文、译文、语言、生成时间和当时的偏好来源。按生成时间过期，命中不续期；过期记录不复用，后续写入时清理。

个人记忆由你明确保存的修正、表达选择或确认的 AI 建议建立。最多 100 个术语版本、40 个表达习惯版本、200 条变更记录、12 个自定义领域。每项保留适用范围、最多 12 个上下文词和最多 30 个使用摘要；按服务账号、语言、场景及领域匹配。领域判断、匹配、数字核对在本机完成，不调用分类或评审模型。个人译法不随缓存过期。

相关阅读在本机匹配共同术语、代码或引用标识，最多向当前界面显示三条相关片段；点击后可取回相应完整记录。它不上传历史、不额外请求模型。忽略的关系最多保存 150 个摘要，可关闭相关阅读或随缓存清空。

反馈与 AI 建议

选择“这段合适”“需要调整”后点击“确认反馈”，或保存明确术语修正时，才建立反馈记录。普通阅读、复制、无操作和缓存命中都不视为认可。最多保存 60 段反馈，包含有限原文/译文片段、类型、时间、语言、场景、领域和去重摘要；原文片段最多 1,000 字符、译文最多 1,400 字符。反馈及其证据片段最多保留 90 天，过期不用于建议，后续写入时清理。

点击“生成建议 · 1 次 AI 请求”，或主动勾选并保存“积累反馈后自动生成建议”，允许将少量反馈片段发送给当前已配置的服务。自动建议默认关闭。只有同一语言、场景和领域中至少三段不同反馈、其中至少两段合适或已纠正时才可整理；每次最多六段。完整输入（指令及片段）最多 8 KiB；请求指定最多 1,024 个输出 token，本机接受回复最多 6,000 字符；20 秒超时，不自动重试。主动与自动共用每个连接每 24 小时一次的额度。失败、停止、无建议的尝试也计入额度，服务可能仍收费；这些上限不保证提供方的内部 token 计费。

模型只能提出短术语或预设表达/排版选项，需引用至少两段有效反馈。未经你确认，不修改偏好或翻译提示。确认后保存领域规则、建议来源及支持反馈数量；不训练模型权重、不执行生成的代码，也不能修改 Key、端点、模型、基础提示、权限或文件。

最多保留 24 条建议记录和 30 条请求记账记录。建议记录含候选、理由、证据片段及确认/撤回状态；证据不会因复制到建议卡中延长其 90 天保留期。删除反馈也移除依赖它的建议卡及片段副本。已确认的译法属于独立保存的个人选择，仍可在个人译法列表撤回或删除。清除反馈与建议保留不含正文的请求记账，以免重置调用额度。切换账号或服务会关闭自动建议，需要重新选择开启；记录按连接账号隔离。

可选 Jev 服务的数据处理

Jev 是与翻译服务分开的建议核对服务，默认未开启。只有你单独填写其 Key 和 HTTPS 地址、启用并保存后，再主动点击待确认建议的核对按钮，才发送该建议的有限字段与引用的反馈片段。默认 GLINK 地址为 matrixcube.alipay.com；你设置的服务会接收这些材料并可能计费，不发送给扩展开发者。不会自动复用或发送主翻译服务的 Key，不上传整个翻译历史、网页地址或其他记忆。

实验性关联核对需另行勾选。只有你点击译文后的核对入口时，才发送当前原文和最多 3 项命中的个人译法或历史原文片段。接收端为你保存的 Jev 服务，主翻译 Key 不随之发送。只返回支持、不匹配或不确定，不修改译文、偏好或历史关联。

每次完整请求最多 8 KiB，接收回复最多 16 KiB，3 秒超时；本机每 24 小时最多 3 次，无自动重试。失败、停止及后台中断仍占用额度，可能已被服务计费。相同建议、证据和 Jev 连接的核对结论在本机复用。概率仅是服务给出的判断信号，不能授权任何自动修改。

Jev 连接与独立 Key 保存在受信任扩展的本机存储；结论、时间和不含明文 Key 的请求摘要随建议记录保存，按该建议的证据保留期处理。关联核对在本机保存最多 12 份结论、时间和请求摘要，24 小时后不再复用；这份缓存不复制原文、术语文本或历史片段。已采纳建议可附带此前 Jev 结论与时间，作为记忆来源而非当前译文质量凭证。最近 24 小时最多三条调用记账仅保存时间、状态、字节量和随机 ID，不含原文；清除反馈不重置调用预算。重置全部本机数据或卸载时删除。关闭 Jev 会停止新核对及正在运行的核对，不删除已保存的主翻译配置或个人译法。

可选的术语试用核对

“术语试用核对（高级）”沿用单独的能力检查：用户主动发送两条固定合成文本和当前翻译指令，不发送历史或个人术语。每条输入最多 4,096 字节、输出请求上限 1,024 token、15 秒超时；24 小时最多三轮检查，相隔至少一分钟。检查次数、配置摘要及通过状态保存在本机，不保存回复正文或隐藏推理。有效期 30 天，连接或相关翻译设置变化后失效。通过后仍需单独开启有限学习。

术语试用仅核对已明确保存的术语：最多三条并行试用、每次一条、每条最多五个不同后续原文；三次局部核对通过保留，连续两次失败或用尽试用预算可撤回。核对不增加模型请求，不认证整体翻译质量。

个人译法备份

主动导出会在你选择的下载位置保存明文 JSON，包含当前连接下的术语、领域及关键词、目标语言、风格和表达偏好；不含 Key、连接地址、完整原文历史、反馈片段、学习证据、使用次数或原有内部 ID。文件中的专业词语仍是个人数据，由你决定如何保管或分享。

导入在本机校验并预览，确认后才写入当前已配置的连接；不上传文件、不调用模型。重复项跳过、冲突保留现有值；条目以手动或暂停状态导入，不恢复旧学习证据。最近一次导入的新增 ID 与连接摘要暂存在浏览器会话存储，供 10 分钟内撤回；不复制备份正文。后续相关操作发现过期时或浏览器会话结束时清除。一次最多 128 KB，100 个术语和 40 个表达偏好，不接受无效文件的部分写入。

控制与删除

单条移除会立即停止该条译文的缓存复用和历史关联。为了支持撤回，浏览器会话存储暂留最近移除的一条完整记录，60 秒后不能撤回；在后续记忆操作发现过期时、被下一次移除替换时、清空译文或浏览器会话结束时清除。个人术语和反馈是独立保存的数据，不随移除译文删除。

关闭“存入翻译记忆”停止自动缓存与复用；已有记录可手动查看，清空时删除。关闭个人偏好停止应用、反馈及建议生成，已保存内容保留。关闭自动建议停止后续自动整理；可手动生成。清除反馈、清空译文、删除个人词条彼此独立；“清除本机数据并重置”删除连接、设置及全部本机记忆。卸载扩展会移除本机存储。已显示内容在更换或关闭窗口前可能仍在内存中。

本机删除不能删除服务方已接收的请求，须按其政策处理。API Key 可在提供方后台撤销。无痕模式未开放。

权限与联系

storage 保存本机数据；activeTab、scripting 提取主动选区及显示授权网页浮窗；contextMenus 提供右键翻译。连接时请求服务域名权限，开启划词时请求网站访问权限。不申请浏览历史、Cookie、麦克风或摄像头权限，没有远程脚本。

隐私问题请通过 Chrome 网上应用店中 ZhuoCs 的联系入口提出。新增数据用途前会更新本说明并提供相应控制。

KnowMe AI Translate — Privacy

Version 2.4.1, updated October 1, 2026. Publisher: ZhuoCs.

KnowMe uses your selected AI provider’s key or an authorized compatible service. There is no developer translation proxy, account service, advertising or analytics. Data is not sent to the extension developer.

KnowMe's use of information follows the Limited Use restrictions of the Chrome Web Store User Data Policy: only the disclosed translation, reading, caching and user-controlled preference features use it. Data is not sold or used for advertising, credit decisions or unrelated purposes. The developer has no backend for reading translations or personal memory. Transfers to your chosen services serve only the corresponding features you enable.

Selected, pasted, typed or explicitly opened text, translation instructions, language/profile choices and matching personal preferences are sent by HTTPS to your configured provider. The default selection mode shows a button first; direct mode sends on selection. Requests allow up to 20,000 source characters and a shared 512-byte personalization addition. The provider receives your key for authentication and may retain requests or charge under its own terms. KnowMe does not collect browsing history, account passwords or unselected full-page content for translation.

Connections, keys, translations, preferences, feedback and Jev configuration are encrypted locally using AES-GCM 256. A local passphrase derives the key using PBKDF2-SHA256 with 600,000 iterations; the passphrase is neither saved nor transmitted. Trusted extension session storage holds the unlocked key and working data until the browser restarts or the extension updates. Ordinary UI preferences, sizes and selection switches remain unencrypted. Forgotten passphrases cannot recover encrypted memory. Nothing syncs to a browser account.

Migration writes and verifies ciphertext before removing active legacy plaintext entries; failed verification preserves the originals. It does not promise erasure of historical disk remnants. An unlocked extension necessarily handles plaintext and cannot protect against software controlling the browser or operating system. Legacy encrypted data requires its original passphrase.

The cache defaults to 30 days on new installs, adjustable from 1–365 days; upgrades retain the previous setting. It holds up to 500 entries / about 6 MiB, including source, translation, language, creation time and original preference receipts. Cache hits do not renew age. Expired data is not reused and is cleaned on subsequent writes.

Personal preferences come from corrections, preset style choices or AI suggestions you explicitly confirm. Limits: 100 term versions, 40 style versions, 200 change events and 12 custom domains. Each may store 12 context words and 30 distinct usage digests. Preferences are scoped to service account, language, reading profile and domain; they do not expire with cached translations. Domain routing, term checks and number checks run locally with no classifier or judge requests.

Related reading uses local shared terms, code or citations. It reveals up to three excerpts and an individual full entry on demand, without uploading history or additional model calls. Up to 150 dismissed relationship digests are stored and removed when cache is cleared.

Optional quick start

First installation opens an optional guide; updates do not reopen it. Reopen it from Settings. Only an explicit translation click sends its public example text to your configured service and may incur provider charges. Wording changes require explicit saving. The guide uses normal translation, cache and memory receipts, without synthetic results, analytics or uploaded progress.

Explicit connection test

Save & test connection sends one fixed Hello translation and fixed instructions to the saved model endpoint, authenticated with its key. It does not send custom prompts, source history, feedback or personal terms. Limits are 1,024 requested output tokens, 256 locally accepted characters and 20 seconds, with explicit cancellation and no retry. Provider charges may apply. The temporary UI receipt shows elapsed time and outcome; the response is not persisted or added to translation, feedback or learning records. Ordinary Save makes no test request.

Explicit feedback and optional AI suggestions

Feedback is recorded only after you choose a rating and click Confirm feedback, or save an explicit correction. Copying, reading, inaction and cache hits are not approvals. Up to 60 feedback entries retain bounded excerpts, type, time, language, profile, domain and deduplication digests. Each source excerpt is limited to 1,000 characters and translation excerpt to 1,400. Feedback and copies of its evidence expire within 90 days; expired material is excluded, with physical cleanup on later writes.

“Find suggestions · 1 AI request”, or explicitly enabling and saving automatic suggestions, authorizes sending a small batch of excerpts to the configured provider. Automatic suggestions are off by default. A batch needs three different passages in the same language, profile and field, including two suitable or corrected examples; at most six excerpts are sent. Total input is capped at 8 KiB, requested output at 1,024 tokens, locally accepted output at 6,000 characters and duration at 20 seconds. No automatic retry. Manual and automatic runs share one attempt per connection per 24 hours, including failures, cancellations and empty results. Provider charges may still apply, and internal provider token billing is not guaranteed by these limits.

A model may only propose short term pairs or preset writing/layout choices, citing at least two valid examples. Confirmation is required before preferences change. Confirmed choices retain their domain and AI-feedback origin. No model training, executable-code generation, or changes to keys, endpoints, model IDs, base prompts, permissions or files are authorized by suggestions.

Up to 24 suggestions and 30 request-accounting entries are kept locally. Suggestions contain candidates, reasons, evidence and status; evidence copies do not extend the original 90-day retention. Deleting feedback removes dependent suggestion cards and excerpt copies. Confirmed glossary choices remain independent and can be reverted or deleted separately. Clearing feedback/suggestions retains accounting without excerpts to preserve request limits. Changing service/account disables automatic suggestions until re-enabled; stored material is isolated by connection account.

Optional Jev review service

Jev is separate from the translation service and off by default. After separately entering its HTTPS endpoint and key, enabling and saving it, an explicit review click sends only one pending suggestion and its cited feedback excerpts. The default GLINK host is matrixcube.alipay.com. The configured service receives and may charge for these requests; the developer does not. The main translation key, full history, page URLs and unrelated preferences are never included.

The experimental connection review requires another opt-in and an explicit click after translation. It sends the current source and up to three matched terms or historical source excerpts to the configured Jev service. Up to 12 verdict-only cache entries are kept locally and reused for up to 24 hours, without copying source excerpts. Adopted suggestions may retain an earlier review verdict and time as provenance, not certification of later translations.

A request is capped at 8 KiB, response at 16 KiB, timeout at 3 seconds and local use at 3 attempts per 24 hours, including failures/cancellations. No automatic retry. Provider charges can still apply. Identical evidence and Jev connection reuse a local receipt. Scores are advisory signals, never authority to change preferences.

The separate key and endpoint are stored locally in trusted extension storage. Review results, time and a request digest without a plaintext key remain with the suggestion and its evidence retention. Accounting retains up to three recent attempts with timestamps, status, size and random IDs, but no excerpts. Clearing feedback does not reset budget. Full reset or uninstall removes this data. Disabling cancels current and future reviews while preserving the main connection and saved preferences.

Advanced term-trial checks

The optional compatibility check sends two fixed synthetic texts with current translation instructions, not history or personal terms. Each input is capped at 4,096 bytes, requested output at 1,024 tokens and time at 15 seconds. Up to three checks per 24 hours, at least one minute apart, without retries. Local receipts contain attempt times, settings digests and pass/fail results, not model responses or hidden reasoning. They expire after 30 days or relevant setting changes. Passing does not enable trials automatically.

Trials only concern explicitly saved terms: three simultaneous trials, one per translation, five distinct later passages each. Three local passes retain a term; two consecutive failures or budget exhaustion may revert it. Local checks do not add model calls or certify semantic quality.

Personal wording backup

An explicit export downloads plain JSON with terms, domains and their cues, target languages, profiles and writing preferences from the current connection. It excludes keys, endpoints, full source history, feedback excerpts, learning evidence, use counts and previous internal IDs. Terminology can still be personal data; you control storage and sharing of the file.

Import is validated and previewed locally, then written only after confirmation to the configured connection. No file upload or model call occurs. Duplicates are skipped and existing conflicts kept. Entries become manual or paused preferences without old learning evidence. Session storage temporarily keeps newly added IDs and the connection digest for a ten-minute undo, without copying backup text; it is cleared on a later relevant operation after expiry or the end of the browser session. Maximum 128 KB, 100 terms and 40 writing preferences. Invalid files are not partially imported.

Controls

Removing one translation stops its cache reuse and historical links. Session storage temporarily retains the last removed full record for undo, which is available for 60 seconds. The copy is cleared when a later memory action detects expiry, another removal replaces it, translations are cleared, or the browser session ends. Personal terms and feedback are separate and are not deleted with the cached result.

Disable automatic caching, selection, personal preferences, related reading or automatic suggestions separately. Disabling preserves existing data. Clear translations, clear feedback or delete glossary entries independently, or reset all local data. Uninstalling removes extension storage. Current windows may retain displayed data until replaced or closed. Local deletion cannot remove data already held by your provider. Keys can be revoked with that provider. Incognito mode is not enabled.

Permissions: storage for local data; activeTab and scripting for requested selection capture and authorized panels; contextMenus for selection actions. Provider and website permissions are requested when connecting or enabling selection. No history, cookie, microphone or camera permissions and no remote scripts.

For privacy questions, use ZhuoCs’s contact entry in the Chrome Web Store. New data uses require an updated notice and corresponding controls.
